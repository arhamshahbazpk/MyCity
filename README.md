# MyCity Services

This repository contains the microservices for the MyCity application.

## Services

* **location-service**: Handles location-related functionality.
* **matching-service**: Handles matching logic.
* **ride-service**: Handles ride management.

## Getting Started

A `docker-compose.yml` file is provided at the root level to orchestrate the services. Each service contains its own specific configuration and `.gitignore` inside its respective directory.
